## Español

Plugin de Paper para servidores LifeSteal. Tras morir en PvP hay 48 horas para derrotar al asesino; cada venganza cumplida suma prestigio y puede subir tu título en la Crónica de Rivalidades. Funciona sin ningún plugin de corazones.

- **Descarga:** el fichero `TemporadasLifeSteal-0.7.0.jar` está en la pestaña **Releases** de este repositorio.
- **Requisitos (según declara el plugin):** Paper 1.21 o posterior; Java 21 para Minecraft 1.21.x y Java 25 para 26.x. Folia no está soportado y Spigot no vale.
- **Instalación:** con el servidor parado, copia el `.jar` en la carpeta `plugins` y arranca. Antes de preparar la primera temporada hay que activar `nueva-temporada` en `plugins/TemporadasLifeSteal/config.yml`, que no trae valores de serie.

## English

Paper plugin for LifeSteal servers. After a PvP death you have 48 hours to defeat your killer; each completed revenge earns prestige and can raise your title in the Rivalry Chronicle. It works without any hearts plugin.

- **Download:** `TemporadasLifeSteal-0.7.0.jar` is in the **Releases** tab of this repository.
- **Requirements (as declared by the plugin):** Paper 1.21 or later; Java 21 for Minecraft 1.21.x and Java 25 for 26.x. Folia is not supported and Spigot does not work.
- **Installation:** with the server stopped, copy the `.jar` into the `plugins` folder and start it. Before preparing the first season, enable `nueva-temporada` in `plugins/TemporadasLifeSteal/config.yml`, which has no default values.
